## Doporučení úpravy architektury (A3)

**Doporučeno (A) — MotionSpec zůstává, mění se kompilační cíl: prompt-compiled motion + verifikace.**
- Maska + trajektorie + kamera se v UI kreslí dál (per-element workflow se nemění).
- Kompilátor místo Kling payloadu generuje **strukturovaný textový prompt** (pojmenování prvku z vrstvy/SAM, směr+velikost pohybu odvozené z trajektorie, kamera slovy) pro současné modely: Kling 2.6/3.0, Seedance 2.5, Veo 3.1, Wan 2.6.
- **Closed-loop verifikace**: po vygenerování pixel-diff klipu vůči masce (metodika ze smoke testů) → UI ukáže „hýbalo se to, co mělo" / nabídne retry. Per-element KONTROLA se zachovává jako zadání + verifikace, i když API mask vstup nemá.
- Premortem #1 mitigace („prompt-fallback od začátku") se tímto povyšuje z fallbacku na primární cestu.

**(B) volitelný doprobe (~$0,35):** `static_mask_url` na v1.5/pro — inverzní sémantika (region, který se NESMÍ hýbat). Poslední neotestovaný mask mechanismus na API. Nízká šance vzhledem k výsledku dynamic_masks, ale levné a definitivně uzavře kapitolu.

**(C) minimalizace:** motion osa jen globální pohyb+kamera promptem, per-element UI odložit do doby, než nějaký provider mask control znovu vystaví.
