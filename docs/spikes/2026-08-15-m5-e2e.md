## Nálezy

**A) SAM `apply_mask`: default mění sémantiku výstupu.** Bez explicitního
`apply_mask: false` vrací box mód v `masks[]` VYŘÍZNUTÝ OBRAZ; `convert("L")`
pak vyrobí alfu z jasu obsahu (Pearson alfa×jas = 1.000; tmavý bronz →
medián alfa 59 → „maska“ >127 jen 2,47 %). Fix `3a874d3`: `apply_mask: false`
VŽDY. Detailní tabulka: `docs/capabilities/sam3-point.md`. → LEARNINGS.

**B) Verifikace: ECC-only nezvládá generativní zoomy.** Reálný M3 klip
(zoom_in 0,25 → model vyrenderoval ~3,5× nájezd, jas +24/255): ECC z identity
skončilo v near-identity minimu (residual 54,2 ≈ raw 55,4, cc 0,4). Řešení
`bca5ed0`: ORB+RANSAC po sousedních párech (RANSAC vyřazuje pohybující se
prvky), kompozice na frame 0, ECC jen refinement, 13 vzorků místo 5, jasový
offset z mediánu pozadí. → LEARNINGS.

**C) E2E tooling (Chrome/Konva):** CDP `left_click_drag` nedodal Konvě
mousemove stream → drag se vyhodnotil jako klik; navíc přepnutí nástroje
přidá hint řádek a posune plátno o ~24 px (staré screenshot souřadnice míří
vedle). Spolehlivé: syntetické MouseEventy na `.konvajs-content` s čerstvým
`getBoundingClientRect` + `await sleep()` mezi eventy (React batching — bez
yieldu mouseup vidí starý state). Pozor na `el?.click() ?? fallback.click()`
— `click()` vrací undefined, fallback se spustí TAKÉ (dvojité vysypání v
destructive logu; server to ustál).

## Známé limity (nové/potvrzené)

- Lev (bbox 26,6 % plochy) crop nespustí — práh `CROP_MAX_MASK_FRACTION`
  0.25 je konzervativní; zvednout až podle reálné potřeby (M6 kandidát).
- Session útrata se nuluje s restartem API (M4 known limit — potvrzeno;
  projektový ledger drží vše).
- Verifikační residual na generativním footage neklesá k nule (obsah
  morfuje — dav, přepózování); atribuce in/out funguje i tak.
- Reference generace bez převzetí zůstává jen v session ledgeru (by design).
